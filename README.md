# Phoenix Tech Solution – Corporate Website & Portfolio

A modern, visually stunning, and professional corporate website & portfolio for **Phoenix Tech Solution**.

## Technology Stack
- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 6
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion & Interactive HTML5 Perspective Wave Canvas
- **Icons:** Lucide React

## Brand Color Palette (Extracted from Official Logo & Cinematic Video)
- **Primary Navy / Deep Space:** `#030712`, `#060B18`, `#0A1128`
- **Secondary Electric Blue / Cyan:** `#00E5FF`, `#38BDF8`, `#0077FE`
- **Accent Phoenix Fire / Amber:** `#FF6A00`, `#FF8800`, `#FFAA00`
- **Glassmorphic Panels:** `rgba(7, 13, 30, 0.85)` with `backdrop-filter: blur(16px)`

## Official Content Placeholder Management
In accordance with company guidelines, no fictional data, fake client projects, or imaginary testimonials were used. When official company materials arrive:
- **Company About Copy:** Edit in `src/components/About.tsx`
- **Executive Profiles (CEO & COO):** Update names, portraits, and bios in `src/components/Leadership.tsx`
- **Contact Details:** Update official email, phone, and address in `src/components/Contact.tsx` and `src/components/Footer.tsx`
- **Backend Mailer Integration:** Wire form action in `src/components/Contact.tsx` to your live API endpoint.
